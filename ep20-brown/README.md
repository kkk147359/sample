# ep20/21「やわらかいブラウンノイズ」

【黒画面でまぶしくない】やわらかいブラウンノイズ 1時間／8時間｜低音ひかえめ・ずっと一定・物音をやさしく隠す｜10秒で真っ暗・睡眠・作業用BGM

ブラウンノイズは自然の録音ではなく決まった形の信号なので、実録音の測定のかわりに傾き（dB/oct）・低域カット・左右の相関を社長のブラインド試聴で決める（企画の条件）。

| ファイル | 役割 |
|---|---|
| `synth_noise.py` | 白いノイズ＋傾きの FIR（45Hz以下カット、8kHzより上はさらに下げる）。ブロックの重ね合わせで継ぎ目なし |
| `trial.py` | 聞き比べ用3種（音量 -23LUFS でそろえる）。対応は `BLIND_KEY.md` |
| `render_long.py` | 長い版。`python3 render_long.py ep20_1h.m4a 3600 2001 -4.5` |
| `make_visual.py` | 背景（夜のカーテン越しの街灯）・サムネイル・冒頭映像 |
| `make_meta.py` | タイトル・説明文・タグ（`python3 make_meta.py -4.5` または `-6`） |
