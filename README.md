# Quiet Hours BGM 制作リポジトリ

YouTube黒画面BGMチャンネル「Quiet Hours BGM」（@QuietHoursBGMjp）の音・映像を作るスクリプト置き場。
運営の決まり（企画会議・審査・決裁・社内ボード）は業務マニュアル（スキル quiet-hours-company）、
サムネイル・冒頭映像・タイトル・説明文・タグの規定はブランドルール（スキル quiet-hours-bgm-brand）に従う。

| フォルダ | 中身 |
|---|---|
| `ep16-koto/` | ep16/17「水琴窟と低い琴の音」（1時間・8時間）。音の合成から動画・Drive納品までの一式。手順は `ep16-koto/README.md` |
| `tools/` | 実録音の検索・測定と、作った音の検査に使う小さなスクリプト |
| `ep16-guitar/` | ep16 の最初の試作（ギター、社長評価30点で不採用）。参考に残している |

## 1テーマの作り方（ep16/17 で固まった流れ）

1. **企画**：企画部と品質チェック部は別エージェントで。結果は社内ボード（ideas / log）へ。
2. **本物の音を先に測る（社長指示）**：作る前に、同じ音の実録音を2本以上探して測る（`tools/`）。
   - freesound.org・Wikimedia Commons を使う場合は、クラウド環境のネットワーク設定で
     `freesound.org` `cdn.freesound.org` `commons.wikimedia.org` `upload.wikimedia.org` を許可する。
   - 録音は測定だけに使い、作品には入れない。測定後は削除し、使った録音と分かったことを `REFERENCES.md` に書く。
3. **合成**：測定値（倍音の配分・減衰時間・密度・音量差）に合わせて Python で作り、同じ道具で測って比べる。
   - 音は聞けないので、数字が合っても自然かどうかは社長の試聴で決める。
4. **短い試聴版を社長に出す**（60〜180秒）。OKが出てから長い版へ。
5. **検査**（毎回）：
   - 4〜5kHz帯の割合（耳鳴りのような音）：`tools/spectrum.py`
   - 急な音（びっくりする音）：`tools/sudden.py`。実録音の水琴窟は上位1% 6.2dB・最大16.8dB。ep16/17 は最大16.5〜16.8dB
   - 低音の圧迫感、風のような音が出ていないか（社長が嫌った音の一覧は業務マニュアル）
6. **長い版・映像・メタデータ・納品**：`ep16-koto/README.md` の手順。
7. **ボード更新**：videos の status（producing → ready）と log。公開は社長（予約 1時間版19:00・8時間版19:30）。

## 社長の音の好み（ここまでで分かったこと）

- 本物との乖離を嫌う。作る前に実録音を測ること。
- 高音が強い楽器は睡眠に向かない（箏 → 低音の十七絃風に変更）。低音そのものは問題ない（10/4）。
- 急に音が出てこないこと。出だしをなめらかに（立ち上がり、強さのばらつき、間の長さで調整）。
- 過去に嫌った音：風のような謎の音、低音の圧迫感、強すぎる雨音、迫ってくる波、不自然な火のはぜる音、
  せせらぎに聞こえない水音、4〜5kHzが続く耳鳴りのような音。
