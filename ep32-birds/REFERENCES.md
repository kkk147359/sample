# ep32/33「小鳥来る、晩秋の朝の庭」測った実録音（2026-10-14、測定のみ。作品には使わず、測定後に削除）

社長指示（10/14）：音の種類ごとに、AI生成ではない実録音を10本以上確認してから作る。
すべて freesound のプレビュー音声（人がフィールドで録った録音、2006〜2023年ごろ）。先頭 2.5MB だけ取得して測り、音声は削除した。
Wikimedia Commons の xeno-canto 写し（スズメ XC347807、エナガ XC114614）は取得に失敗したため使っていない。
測定：`tools/birdcalls.py`（1声ずつ）、`tools/forest.py <file> 1500 8000`（鳴き声のない間の空気）、`tools/ambience.py`、`tools/sudden.py`。

## 当時の却下理由（ideas i-2026w42-3、10/12 審査）と、この試聴版での対応

| 却下理由 | 対応 |
|---|---|
| 小鳥の声の中心は 3〜7kHz、4〜5kHz が中核。鳴き交わすと積み重なって耳鳴りのように聞こえる。下げすぎるとこもる | 実録音で確かめると、近い録音はファイル全体の 4〜5kHz が 7〜31%（中央）だが、遠くの小鳥の録音（日本の公園・森・寺）は 0.01〜0.65%。「遠くで、ときどき、短く」鳴かせる形にし、高さは日本の公園・森の録音どおり 3〜4kHz 中心（声のある時間の 4〜5kHz 12%、実録音の遠い声 7〜51%）。声そのものは削らないので、こもらせていない |
| 実録音は英国の種、鳥の合成は本物と違う音になりやすい | 日本の録音 7本（メジロ、東京の公園2本、松戸、富士山麓の森、高山の寺、伊那）を入れて測り、声の長さ・高さ・下がり方・間隔・背景との差を合わせた。自然に聞こえるかは試聴で判断 |
| 鳥の自然音は Content ID の申し立てが多い | 録音は使わず、すべて合成 |
| 同じ週に鳥2本、「朝・明るい」は夜のブランドと方向が違う | フクロウ（ep30/31）は 10/20 公開予定なので、公開日をずらす。朝の声を明るく元気にせず、遠く・まばらにする |
| 「小鳥来る」は秋（仲秋）の季語で晩秋ではない | 社長がこの題で決定（10/14）。タイトルはメタデータ作成時に確認 |
